# 本地增量备份 / Incremental Backup

为思源笔记提供**本地自动增量备份**：基于硬链接的时间点快照（Time Machine 风格）。

## 功能

- **定时自动备份**：频率可选**每天一次 / 每周一次 / 每 2 小时 / 自定义分钟**（默认每 60 分钟），自动执行且等待思源**空闲**（默认 2 分钟无键鼠操作）后才启动，不干扰编辑
- **每日首启备份**：每天第一次打开思源时自动备份一次（可关）
- **真增量**：与上一份完整快照比对（尺寸 + 修改时间，2ms 容差），未变化的文件用**硬链接**共享，每次备份实际写入量通常只有几 KB
- **多版本可回溯**：每份快照都是完整目录树，删除/修改源文件不影响历史快照
- **快照管理**：插件内浏览全部快照（时间/文件数/变更量/备注），支持单份删除、打开、备注标签
- **恢复向导**：
  - *导出到文件夹*：把任意快照完整复制到指定位置，最安全
  - *覆盖还原*：用快照还原工作空间，**还原前自动生成一份安全快照**，完成后引导重启
- **自动清理**：超过保留份数（默认 30）时自动清理，最近 10 份无条件保留，更早的按自然日去重；快照备注写在清单里随快照保留
- **备份范围可选**：data（笔记/资源/插件）、conf（配置）、history、repo
- **备份中不卡界面**：异步分批处理，顶栏图标实时显示进度
- **目标路径选择**：设置里支持系统目录选择对话框，也可手动输入

## 稳定性设计

- **半成品治理**：快照以 `_manifest.json` 写入完成为「完整」标志。备份中断/取消的半成品会被立即删除或启动时自动清理，**绝不作为硬链接基准**
- **磁盘空间预检**：备份前检查目标盘剩余空间（首次需 源体积×1.15+50MB，增量需 100MB），不足时中止并明确提示
- **防递归自备份**：拒绝把备份目录设在工作空间内部
- **失败节流**：自动备份失败后按 `lastAttemptAt` 节流，不会每 30 秒重复触发全量扫描
- **友好报错**：ENOSPC/EACCES 等错误码映射为中文提示
- **日志轮转**：`backup.log` 超过 1MB 自动截断保留尾部

## 工作原理

每次备份在目标目录生成 `snap-YYYYMMDD-HHMMSS/`：

```
~/SiYuanBackup/
├── snap-20260829-130419/     ← 完整目录树（与工作空间结构一致）
├── snap-20260829-140419/     ← 未变化文件 = 上一份快照的硬链接
├── ...
└── backup.log                ← 备份日志（自动轮转）
```

硬链接共享意味着：**占用空间 ≈ 首份全量 + 每次备份的变更量**，而不是份数 × 体积。

## 安装

本插件已部署在 `data/plugins/siyuan-incremental-backup/`。重启思源后，在 **设置 → 集市 → 已下载** 中启用即可。

仅支持**桌面端**（依赖本地文件系统）。

## 使用

1. 启用插件后，顶栏出现备份图标
2. 点击图标 → **备份设置**：选择备份位置（默认 `~/SiYuanBackup`）、范围、间隔、空闲阈值、保留份数
3. 点击 **立即备份** 执行首次全量；之后按间隔自动增量
4. 点击图标 → **快照管理 / 恢复**：浏览、备注、删除快照，或进入恢复向导

命令面板支持 `立即备份` 命令，可自行绑定快捷键。

## 恢复

### 方式一：插件内恢复（推荐）
顶栏 → 快照管理 → 选择快照 → 恢复：
- **导出到文件夹**：不影响当前工作空间，最安全
- **覆盖还原**：自动先做一份「还原前安全快照」，再覆盖工作空间，完成后按提示重启思源

### 方式二：手动恢复
1. 完全退出思源
2. 把要回滚的时间点快照里的 `data/` 覆盖回 `~/SiYuan/data/`（建议先把当前 data 改名为 `data-broken` 留底）
3. 重新启动思源

## 注意事项

- 备份位置**不要**放在工作空间内部（插件会拒绝）
- 首次全量约需数秒（916MB 约 4 秒，SSD 实测），此后每次增量通常不到 2 秒
- 备份目标在外置硬盘/网络盘上时硬链接不可用，插件会自动退化为普通复制（仍为增量语义，但每份快照占用全量空间）
- 本插件是**本地备份**，与思源自带的云端同步/快照互不冲突，建议同时保留
